RSI is a spectrum

Models are moving from answering questions about machine learning to running parts of the pipeline that trains them. Each step up needs training signal the previous generation couldn’t produce. That signal is what we build.

  1. Stage 1Answers

    Explains ML methods. Runs nothing.

  2. Stage 2Assists

    Writes code that a researcher runs and judges.

  3. Stage 3Executes

    Runs a bounded experiment end to end.

  5. Stage 4Owns a stage

  6. Stage 5Builds the pipeline

EnvironmentsSubscriptions that keep pace with your models

High-fidelity environments for the work that builds models, kept in the band where your models still learn from them.

Tasks are discovered, not hand-written. Frontier models propose candidates just beyond their own reach, and a candidate becomes an environment only if its reference solution runs and it holds up when the strongest available model tries to break it.

Every task keeps its lineage: where it came from, what was rejected on the way, and which failure it targets. That record is what lets us maintain an environment instead of shipping it once, and each model we evaluate sharpens the next search. A stronger successor model then proposes harder tasks for the next round.

Successor tasks
When pass rates near saturation, a task is replaced by a harder successor discovered against your current model, instead of being retired.
Hidden splits
Held-out data rotates on a schedule, and we monitor for contamination.
Exploit patches

Current stacks

Stateful variants
